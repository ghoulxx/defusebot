1. Information We Collect

We may collect and store the following information when the Bot is used:

  • server IDs, channel IDs, and role IDs
  • user IDs, usernames, and moderation-related records
  • warnings, bans, mutes, jail status, notes, and audit entries
  • ticket metadata, assigned staff, and ticket channel information
  • economy balances, transactions, leveling progress, rewards, and XP
  • giveaway configuration, winners, and expiration details
  • voice channel settings and temporary voice channel state
  • reaction role, button role, welcome message, and logging configuration
  • custom prefix and feature settings configured by server administrators
  • command usage and operational logs required for maintenance and support

We do not intentionally collect payment information, passwords, or private messages unless specifically required for a feature and clearly disclosed to the server administrator.

We use collected data to:

  • operate moderation, anti-abuse, and security features

Server administrators and users may contact the Bot owner or support team to ask questions about stored data or request information relevant to their privacy rights, where applicable.
